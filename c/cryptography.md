# Cryptography

`Cryptography` is the science and practice of using mathematical techniques to protect and secure information against unauthorised access, alteration or impersonation.

The main applications of cryptography are:
- encryption – converting readable information into an unreadable form so that only authorised parties can read it
- hashing – creating a fixed-size digital fingerprint of data, allowing changes to the data to be detected
- authentication – verifying the identity of a person, device or system
- digital signatures – proving that someone has approved particular data
