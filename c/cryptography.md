# Cryptographic algorithms

A `cryptographic algorithm` is a precisely defined mathematical procedure that operates on data, in order to protect and secure it against unauthorised access, alteration or impersonation.

There are two main kinds of cryptographic algorithm:
- a `keyed` cryptographic algorithm takes two inputs – some data, and a cryptographic key
  - encryption and decryption algorithms
- an `unkeyed` cryptographic algorithm takes just the one input, the data itself
  - hashing algorithms

AES - symmetric block encryption algorithm
AES-128
AES-192
AES-256


The main applications of cryptography are:
- encryption – converting readable information into an unreadable form so that only authorised parties can read it
- hashing – creating a fixed-size digital fingerprint of data, allowing changes to the data to be detected
- authentication – verifying the identity of a person, device or system
- digital signatures – proving that someone has approved particular data
