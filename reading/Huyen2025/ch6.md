## 6.2. Agents

The unprecented capabilities of foundation models have opened the door to rational agentic applications — assistents, coworkers, coaches, etc. 
The potential exonomic value of these agents is enormous. 

### 6.2.1. Agents overview

An agent can both perceive its environment and act upon it. 

An agent acts upon its encironment using tools. Simple tool include: web search engines, Python code executors, image generators. 

Agents need more powerful models for 2 main reasons:
- agents need multiple steps to accomplish a task, so mistakes can compound
- since agents can access tools, the stakes are higher.
